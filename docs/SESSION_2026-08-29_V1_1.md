## Challenges and remediation

The first local demo invocation failed because running a file from `scripts/`
did not place the repository root on Python's import path. CI had hidden this with
an injected `PYTHONPATH`. The documented and CI command now uses
`python -m scripts.demo`, giving local and CI verification the same import behavior.

Security inspection also found that the operator queue interpolated stored lead
values into `innerHTML`. All untrusted rendered values are now HTML-escaped, closing
the stored cross-site scripting path without changing the demo experience.

## Current limitation

The audit record describes internal decisions only. External provider attempts,
retries, delivery results, and appointment outcomes remain unimplemented because
there are intentionally no real external adapters. Operator authentication,
tenant isolation, and production persistence are also required before live
customer data is appropriate.
